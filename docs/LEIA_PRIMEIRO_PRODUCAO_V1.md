## Diretriz

Forge Street não será tratado como MVP mínimo.

O objetivo é entregar um jogo mobile completo, robusto, expansivo, visualmente premium e monetizável.

O time está autorizado a:
- melhorar ou substituir arte;
- redesenhar UI/UX;
- aprofundar progressão;
- criar distritos;
- criar Blueprints, Masterworks, Contracts e LiveOps;
- implementar monetização completa;
- construir infraestrutura comercial.

## POCO F4

Não utilizar como ferramenta de regressão diária.

Reservar para:
- Feature Complete;
- Release Candidate;
- bug Android físico específico;
- build final de publicação.

Durante desenvolvimento usar automação, emulador, CI, device farms e testadores externos.

## Primeira ação do time

Mapear todo o projeto atual como:

- KEEP
- UPGRADE
- REPLACE
- NEW

Depois criar os tickets seguindo as Waves A → I do Documento Mestre.

## Regra

Preservar as vantagens técnicas existentes:
- FS.Core;
- simulação determinística;
- bot;
- testes;
- mutation testing;
- proveniência;
- pipeline de criativos.

Não preservar fraquezas visuais ou de produto por apego ao trabalho anterior.
